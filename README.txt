RICIKANSKETCH.ID — WEBSITE PACKAGE

Isi:
- index.html: website responsif satu halaman, tema hitam-gold
- assets/: logo, gambar pricelist, dan foto katalog yang dikirim

Cara melihat:
1. Ekstrak ZIP.
2. Buka index.html di browser.

Cara publikasi:
- Upload seluruh isi folder ini ke layanan hosting statis seperti Vercel, Netlify, atau GitHub Pages.
- Pastikan index.html dan folder assets berada pada direktori publik yang sama.

Catatan:
Empat kategori katalog belum memiliki gambar yang cocok/terpisah pada file yang dikirim (Klat Bahu Custom, Uncal Buto, Endhong, Praba/Badhong), sehingga ditandai "Foto katalog menyusul". Gambar pricelist disertakan sesuai unggahan. Tombol WhatsApp menggunakan nomor 089669188456 dengan format tautan internasional +62.
